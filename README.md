# Новий Рівень — Секретне відео за 30-значним паролем (Serverless)

Автономний веб-сайт у фірмовому темно-зеленому неоновому стилі **«Новий Рівень»** («Партія на висоті!»).
Працює **повністю без сервера** (Client-Side Only), використовуючи сучасні криптографічні стандарти **Web Crypto API (AES-256-GCM + PBKDF2 SHA-256, 100 000 ітерацій)**.

---

## 🔒 Як працює захист (Чому це безпечно без сервера?)

1. На сервері/хостингу **немає відкритого відео і немає збереженого пароля**. Там лежить лише зашифрований файл `video.enc`.
2. Користувач переходить на сайт за QR-кодом зі смартфона та вводить свій 30-значний ключ доступу.
3. Браузер генерує криптографічний ключ прямо в оперативній пам'яті через PBKDF2 і намагається розшифрувати `video.enc` алгоритмом AES-256-GCM.
4. **Якщо пароль невірний:** автентифікаційний тег GCM відхиляє розшифрування — відео неможливо підглянути чи переглянути в DevTools.
5. **Якщо пароль вірний:** відео розшифровується у безпечний локальний `Blob` у пам'яті браузера та миттєво відтворюється.

---

## 📁 Структура проєкту

- **`index.html`** — головна сторінка для користувачів із неоновим оформленням, полем вводу 30 символів (із кнопками вставки, приховування/показу та лічильником) та відеоплеєром.
- **`style.css`** — неонові зелені стилі, оптимізовані для мобільних екранів (iOS Safari, Android Chrome) та ПК.
- **`crypto.js`** — криптографічний модуль на базі нативного браузерного `window.crypto.subtle`.
- **`app.js`** — логіка взаємодії, валідації та відтворення відео.
- **`encrypt.html`** — зручна **офлайн-утиліта в браузері** для легкого шифрування відео без встановлення програм.
- **`encrypt.py`** — консольний скрипт Python для альтернативного шифрування через термінал.
- **`assets/logo.jpg`** — фірмовий логотип «Новий Рівень».
- **`video.enc`** — зашифрований файл відео (наразі вже створено тестовий демонстраційний файл).

---

## 🛠 Як зашифрувати ваше реальне відео

### Варіант 1: Через браузер (Найпростіший, без консолі)
1. Відкрийте файл `encrypt.html` у будь-якому браузері (Chrome, Safari, Edge).
2. Перетягніть ваш відеофайл (рекомендовано `.mp4`, до 50–100 МБ).
3. Натисніть **«Згенерувати 30 символів»** або введіть свій 30-значний пароль.
4. Скопіюйте збережений пароль для квесту.
5. Натисніть **«Зашифрувати і завантажити video.enc»**.
6. Перемістіть завантажений файл `video.enc` у папку проєкту (замініть старий).

### Варіант 2: Через Python
```bash
python3 encrypt.py "шлях/до/вашого/відео.mp4" "ВАШ_30_ЗНАЧНИЙ_ПАРОЛЬ_ТУТ_____" video.enc
```
*(Якщо не вказувати пароль, скрипт згенерує надійний 30-значний ключ автоматично).*

## 🚀 Як протестувати локально

Оскільки браузери блокують запити до бінарних файлів за протоколом `file://` через політику безпеки CORS, запустіть простий локальний сервер:

```bash
# У папці проєкту виконайте:
python3 -m http.server 8000
```
Відкрийте у браузері: `http://localhost:8000`

Тестовий ключ для демонстраційного відео, яке зараз зашифровано:
`NOVYI-RIVEN-SUPER-QUEST-KEY-30`

## 🌐 Як опублікувати сайт в інтернет безкоштовно

Сайт повністю статичний, тому його можна розмістити на будь-якому безкоштовному сервісі:

### 1. GitHub Pages (Рекомендовано)
1. Завантажте файли (`index.html`, `style.css`, `crypto.js`, `app.js`, `assets/`, `video.enc`) у репозиторій на GitHub.
2. Перейдіть у **Settings -> Pages**.
3. У полі **Source** виберіть `Deploy from a branch` -> гілка `main` (folder `/root`) -> натисніть **Save**.
4. Через 1 хвилину ви отримаєте посилання виду `https://ваш-нік.github.io/назва-репозиторію/`.

### 2. Cloudflare Pages / Vercel / Netlify
- Просто перетягніть папку проєкту у панель Vercel або Netlify Drop, і сайт миттєво з'явиться в інтернеті з підтримкою HTTPS.
